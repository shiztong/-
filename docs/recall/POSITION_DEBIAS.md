# 位置偏差与召回训练：识别、校正、验证和失效边界

本章讨论“什么内容更容易被看见/点击”，不把所有曝光和点击差异统称位置偏差。[消偏数据流图](diagrams/06-position-debias.svg) · [可执行代码](../../recommender/retrieval/debias.py) · [独立模拟](../../tools/position_bias_demo.py)。当前代码是组件与模拟，**未将位置权重接入六模型训练器，也没有真实业务消偏收益**。

已纳入 [统一交付台账](README.md#2-统一交付与依赖台账)：B1 是 **C（组件已测）**，B2 的真实识别/校准是 P；本专题不再作为独立于总路标的附录任务。

## 1. 至少区分五个变量

| 变量 | 含义 | 常见误用 |
|---|---|---|
| `k_display` | 真实展示槽位，可能包含行/列/卡片形态 | 当成纯线性 rank 或用下发顺序代替 |
| `k_sequence` | 用户历史中的先后/相对距离 | 删除历史位置编码当作展示去偏 |
| `E` | 是否实际检查/获得消费机会 | 将可见或起播与真正关注视为同一事件 |
| `π0(i,k|x)` | 日志策略把内容放在该位置的概率 | 直接用 CTR 或检查概率代替 |
| `e(k,x)` | 给定条件下的检查概率 | 当成任意新策略的完整重要性权重 |

PBM 中的检查与真实兴趣不同；位置与内容相关，是因为旧系统主动把预测较好的内容放前面。直接按位置平均 CTR 拟合一条衰减曲线，通常同时混入质量差异和用户选择。

## 2. 两种场景的偏差不同

### 2.1 列表页

下发→进入可视区→被检查→点击→消费是多个事件。页面下方未出现的卡片不应作为真实拒绝；即使可见，也可能没有得到关注。双列网格、卡片高度、封面、广告混排和首屏位置可能交互。

若样本单位已经限定为“可见曝光”，需要建模的是可见条件下的检查，而不是再无条件除一次可视概率。估计器的条件集要与训练样本一致，否则重复校正。

### 2.2 视频流

第 N 条能否到达依赖此前内容、用户状态、会话退出与预取，而不仅是槽位 N。当前视频已经真实展示且可播放后，起播可能近乎必然；快划仍包含兴趣、播放质量与会话结束。

不能用 `1/到达第N条比例` 自动把深位置内容当作好内容。那需要建模历史条件下的到达选择及支持集；一旦改变前面内容，后面状态分布也改变，属于序列决策问题。首轮可先优化真实播放样本口径、播放故障区分和会话切片，再研究条件选择或长期策略评估。

## 3. PBM 的识别假设

设点击 `C=E*R`，`R` 表示检查后会点击的相关性变量。PBM 假设在所用上下文条件下：

\[
P(C=1|x,i,k)=e(k,x)r(x,i).
\]

它忽略或简化了信任效应、位置改变内容感知、跨卡片竞争和检查相关性。曝光位置本身可能改变用户判断，因此有些 UI 中简单乘积并不成立。

仅从自然日志的 CTR 乘积通常不能唯一分解 `e` 与 `r`。需引入随机化、可识别结构、额外检查信号或其他充分假设；高拟合度不是因果识别证据。

## 4. propensity 从哪里来

### 4.1 随机位置/交换校准

在固定资格内容和适当分层内随机分配槽位，使相关性分布在位置间可比较。若 PBM 条件成立：

\[
CTR(k)/CTR(k_0)=e(k)/e(k_0).
\]

得到的是**相对检查概率**，并非自动知道绝对概率。设 `e(k0)=1` 是尺度约定或额外假设；真实首位检查率未必是 1。对于正例归一化目标，公共比例可能抵消；对于绝对相关率估计，不确定尺度不能省略。

随机交换的 assignment probability 已知，但它仍不是检查概率。校准需按场景、布局、设备、入口等必要维度分层，并避免小样本桶极端权重。位置参考若不是最强检查位置，相对比值可超过 1，不能为了适配代码随意截成合法概率。

### 4.2 可见/播放信号

viewability、进入视区、前台、起播可用性可以观测部分机会，但不是完整心理检查。将其用于过滤、分层或估计时，要说明与 PBM 的 E 是否相同。

### 4.3 点击模型/联合学习

PBM、cascade、DBN 等模型做不同结构假设；DLA 类联合估计相关性和 propensity，不能在无约束自然日志上神奇恢复真值。必须检查初始化、锚点、支持集、跨场景适配、随机保留集和对真实干预的预测。

### 4.4 相关性塔与位置塔分离

另一条可比较路线是在点击预测中分离内容相关性与展示条件。例如：

\[
p_C=\sigma(f_{rel}(u,i,c)+g_{pos}(k,layout,c)),
\]

或 PBM 风格 `pC=sigmoid(frel)*sigmoid(gexam)`。两者并不等价：加性 logit 是条件 log-odds 分解，不是检查概率的乘积分解。

位置塔限制为位置/布局信息，有助控制模型把展示规律直接写进相关性分支，但**仅拆两塔不保证可识别或已消偏**。旧策略仍使内容质量与位置相关；位置也可能通过其他字段泄漏进相关性塔。

服务时用相关性分数、固定参考位置分数或实际位置点击率，是三种决策口径。统一参考位置可以比较候选，但参考输入要有数据支持，并重新做校准；删除位置塔不能天然得到真实兴趣概率。列表页已有布局信息和召回阶段未知最终位置，也不能混为同一个输入合同。

### 4.5 历史画像与 loss 的校正位置

对点击历史按逆检查权重重新统计主题/作者分布，可作为画像去偏实验；给注意力权重乘 `1/e` 再归一化，则改变了非线性聚合目标，并不自动得到无偏用户向量。需要分别比较“只校正正例 loss”“只校正历史统计”“二者联合”，检查高权重噪声与重复放大，不能无条件叠乘。

序列本身还可能存在人工槽位偏置：例如同样有效历史由于 padding 或截断策略变化而落到不同绝对 index。应通过 padding/截断/相对距离一致性测试排查；相对位置和时间编码是建模选择，不是展示检查校正。

## 5. 召回正例目标的逆检查加权

对曝光 i 的正例排序损失 `ℓi=-log Pθ(item_i|user_i)`，满足 PBM 且 e 已知时：

\[
E\left[\frac{C_i}{e_i}\ell_i\mid x_i,i,k_i\right]=r_i\ell_i.
\]

因此可以校正“被点击正例更偏向容易被检查位置”的一部分选择机制。但该期望仍在**日志策略选择的内容与状态分布**上，不是对从未曝光的全库内容无偏。

### 5.1 两种归一化

全曝光行且 click mask 有效时的正例 IPS 目标：

\[
\hat L_{IPS}=\frac1N\sum_{n=1}^N\frac{c_n}{e_n}\ell_n.
\]

归一化重加权正例目标：

\[
\hat L_{SNIPS+}=\frac{\sum_n(c_n/e_n)\ell_n}{\sum_n c_n/e_n}.
\]

后者是比率估计，有限样本不严格无偏；可用作 clicked-only 训练的归一化正例目标，但不能把 click-only 行数当作全曝光 N，再声称估计了绝对风险。无点击 batch 不应产生虚构正例，代码返回零损失。

### 5.2 没有修正什么

- 没有修正内容入选概率 `π0(i|x)`；
- 没有替代 sampled-softmax 的负采样分布修正；
- 没有把未点击变成已观察“不相关”；
- 没有解决没有支持的内容/用户；
- 没有自动修正视频长度、播放失败或延迟标签；
- 没有授权在用户向量中输入本次候选未知的最终展示位置。

不能对所有正负行简单乘 `1/e` 后就称为相关性 BCE。未点击包含未检查，标准二元相关性风险需要另行推导/建模，可能产生负系数与高方差；本代码只提供明确的正例 softmax 目标。

## 6. 代码、裁剪与有效样本量

`examination_weights` 对 `e≤0`、非有限值或超过 1 的概率报错；不会用 floor 伪造零支持。对合法正概率可用 floor 与最大权重：

\[
w_i=\min(w_{max},1/\max(e_i,e_{min})).
\]

floor 和 clipping 都降低方差并引入偏差，应该一起报告比例与敏感性，而不是称为恢复了严格无偏。默认 `emin=0.01,wmax=20` 是演示配置，不是业务推荐定值。

诊断：

\[
ESS=\frac{(\sum_iw_i)^2}{\sum_iw_i^2}.
\]

权重 `[1,1,100]` 的 ESS 约 1.04，而非 3。若用户内样本高度相关，ESS 也不等于独立用户数；置信区间还需用户/随机化单位聚类。分场景、位置、人群分别看权重、clip 比例、ESS 与效果。

核心接口：

```python
from recommender.retrieval.debias import positive_weighted_softmax

# logits: [B,V]；targets: 每条曝光实际展示的 item 在该目录中的索引。
# propensities 来自独立估计/已知机制，不能取 history index 或模型 CTR。
loss = positive_weighted_softmax(logits, targets, propensities,
    clicks=click_mask, reduction='ips', min_propensity=0.01, max_weight=20)
```

代码停止 propensity 和 click mask 的梯度；若要联合学习 propensity，应实现有识别条件的独立目标，不能让 ranker 随意把 e 调大以降低 loss。当前六模型训练器没有位置字段，此组件尚未接线，旧报告不能标记“已消偏”。

### 6.1 真正接线前的位置 sidecar 合同

现有三列交互 JSON 不足以支撑消偏。独立 sidecar 至少保存 `impression_id/request_id/user_key/item_id/event_time/scene/display_slot/layout/visible/playable/click/propensity_value/propensity_kind/reference_slot/estimator_version/conditioning_bucket`，并能与原样本一一关联。

`propensity_kind` 必须区分绝对检查概率、相对检查率、位置 assignment probability、内容 action probability；这些不能共用一个叫 `p` 的无类型字段。保存估计数据窗口、独立校准/交叉拟合规则与置信度，不把未来日志拟合的统计回填为过去可用特征。

绝对正例风险估计要求正确尺度；只有相对检查率时，先明确公共尺度是否能在所用目标中抵消。代码函数只接收数值，真实管线必须在调用前做上述语义校验，不能认为数值落在 (0,1] 就证明来源正确。

## 7. 公开实现核验：ULTRA

已读取 `ULTR-Community/ULTRA@89ffcae` 的 README、`ipw_rank.py`、`base_algorithm.py`、`dla.py` 与 `propensity_estimator.py`。见 [固定来源与哈希](evidence/position-source-manifest.json)。未运行其 TensorFlow 训练，因此不填写效果数字。

重要细节：

- propensity estimator 示例通过**模拟点击 + 随机打乱列表**估计相对权重，并非在任何自然日志上直接识别真 propensity。
- `ipw_rank.py` 中存在三引号包围的旧损失代码，不能把其中注释写的“不加权 softmax”当作当前执行逻辑。
- 实际调用继承的 `BaseAlgorithm.softmax_loss`，它构造 `weighted_labels=(labels+1e-7)*propensity_weights` 后归一化并加权汇总；应沿调用关系审查，而非只看函数名字。
- DLA 的归一化权重使用首位置概率与各位置概率的比，并可裁剪。这个比值不是任意目标策略的 action propensity。

原始研究脉络包括 Joachims 等的 biased-feedback ULTR、Wang 等 personal-search selection bias，以及 Ai 等 DLA；本轮证据是上述可定位源码，不声称重新读取全部论文或复现线上收益。

## 9. 从位置校正到策略评估的边界

若要评价不同选内容策略，需 action-level logging propensity、支持集和奖励定义：`π(a|x)/π0(a|x)` 与 `1/e(k,x)` 是不同对象。DR、IPS/SNIPS OPE 的奖励通常是已选动作的观测回报；若目标是潜在相关性，还需处理检查缺失。

Doubly Robust 需要适当的回报模型与 propensity 条件，不能仅用预测 CTR 减一下残差就声称稳健。视频流中动作会改变后续状态，单步估计不能替代序列策略评价，重要性权重长乘积也可能高方差。

## 10. 实操路线与验收

| 工作包 | 交付 | 关键验收 |
|---|---|---|
| BIAS-01 | 位置/行列/布局/可视/播放/归因 schema | 分清下发、可见、检查与消费 |
| BIAS-02 | 随机位置校准或可识别模型方案 | 支持集、参考尺度、分层稳定性 |
| BIAS-03 | 正例权重 sidecar + loss 接线 | 不混用序列位置、CTR 与 propensity；控制 clip/ESS |
| BIAS-04 | 随机保留集/干预集评价 | 校准与排序改善，不只自然日志 AUC |
| BIAS-05 | 与 SDM 序列优化做 2×2 实验 | 原/新编码器 × 原/校正目标，区分收益来源 |
| BIAS-06 | 线上用户随机实验 | 满意度、有效消费、负反馈、位置/深度切片和成本 |

预期收益取决于旧策略偏差强度、propensity 质量、支持集与新增方差，可能为零或负。不给所有位置消偏项目预设统一提升；先有可识别数据，再给商业门槛与放量结论。
