# 04 列表页精排：交叉、兴趣与消费漏斗

## 1. 输入与总体结构

一次候选评分的输入包括用户、内容、上下文、统计交叉及历史序列。示例结构：

```text
稀疏 ID/类目/作者 → Embedding ─┐
数值特征 → 变换/缺失指示 ────┼→ 交叉网络 + DNN → 任务专家 → 各任务 head
历史序列 × 候选 → 兴趣向量 ──┤
文本/封面/内容语义 → 投影 ───┘
```

稀疏 Embedding 维度按基数、频率和预算选择；高基数 ID 不必与低基数枚举共享维度。连续特征可做 log1p、分桶或归一化，但变换参数必须来自训练期并在线一致。零值与缺失值应区分。

## 2. 显式交叉：DCN 与 FM

令拼接输入为 \(x_0\)。向量形式的交叉层可写作：

\[
x_{l+1}=x_l+x_0\odot(W_lx_l+b_l).
\]

它让基础特征与上一层组合显式相乘。DCNv2 进一步提供更有表达力的矩阵参数化及低秩、专家混合等设计；具体实现应区分全矩阵和低秩版本的成本。

FM 的二阶项：

\[
s_{FM}=\sum_{a<b}\langle v_a,v_b\rangle x_ax_b.
\]

DeepFM 类结构把二阶交叉与深层非线性组合联合使用。适合建立可靠基线；更复杂的 Attention 结构未必在相同预算下胜出。

可显式加入用户对作者消费次数、主题匹配、近期曝光次数等业务交叉。它们通常比让模型仅凭 ID 自行发现关系更省样本。

## 3. 候选相关兴趣：DIN

用户历史 \(H=\{h_1,\ldots,h_L\}\)，候选表征为 \(q_i\)。一种常见实现为：

\[
a_t=MLP([h_t;q_i;h_t\odot q_i;h_t-q_i;\phi(\Delta t_t)]),
\quad h_{u\mid i}=\sum_t\alpha_t h_t.
\]

\(\alpha_t\) 可由 softmax 或非归一化激活获得。原始 DIN 的局部激活思想并不要求所有实现都采用 softmax；两者应通过实验比较。

候选是旅游内容时，模型可强调旅行历史；候选是财经内容时，强调财经历史。这比对所有历史取同一个平均向量更细致。

代价是每个候选都要计算一次历史匹配。候选数为 \(N\)、历史长度为 \(L\) 时，核心交互成本随 \(NL\) 增长。可复用历史投影，但候选相关权重通常不能跨候选共享。

DIEN 在兴趣演化上引入序列状态和辅助监督；它解决的是兴趣如何随行为变化，而不仅是静态匹配。辅助 next-item 损失只能使用当前事件之后的目标做监督，不能把未来行为放入输入。

## 4. 长序列：检索历史再精细建模

当历史扩展到数千事件时，对每个候选全量 Attention 可能不可承受。SIM 类思想可分两步：

1. General Search：通过类目、语义相似度或轻量检索筛选与候选相关的历史。
2. Exact Search：对选中的少量历史计算更精细的候选相关 Attention。

必须保留一部分全局长期兴趣及最近历史，避免检索器丢弃跨主题兴趣。若第一阶段是硬选择，其学习信号与可微 Attention 不同，需单独验证检索覆盖；不能假定后续模型会自动修复已丢失的信息。

## 5. 点击—消费漏斗与 ESMM 思路

设 \(p_C=\sigma(f_C(x))\)、\(p_{Q|C}=\sigma(f_Q(x))\)，定义全空间消费概率 \(p_Q=p_Cp_{Q|C}\)。训练：

\[
\mathcal L= BCE(y_C,p_C)+\lambda BCE(y_Q,p_Cp_{Q|C}).
\]

在真正的 \(Q\subseteq C\) 漏斗下，未点击样本的 \(y_Q=0\) 是事件定义带来的全空间标签。该结构利用全曝光空间监督，缓解仅在点击样本上学习消费头的分布问题。

但它不保证条件头在所有区域均被充分识别，也不能自动消除位置偏差、历史策略偏差和标签噪声。点击极低的区域中，消费条件头可能梯度较弱，需要切片检查。

对点击后时长可增加带 mask 的条件损失：

\[
\mathcal L_T=\frac{\sum_n y_{C,n}\ell(T_n,\mu_C(x_n))}{\max(1,\sum_n y_{C,n})}.
\]

这仍然是在点击人群上学习；如要泛化到整体曝光，必须明确可识别假设及校正方法。最终 \(p_C\mu_C\) 的校准需要在曝光口径验证。

## 6. 多任务共享：MMoE 与 PLE

MMoE 使用共享专家 \(E_j(x)\) 与任务门控：

\[
g_t=\operatorname{softmax}(G_tx),\quad
h_t=\sum_jg_{tj}E_j(x),\quad
\hat y_t=head_t(h_t).
\]

不同任务可以选择不同专家组合。它降低完全共享带来的冲突，但并不保证专家会自然获得清晰语义，也可能发生门控集中和专家冗余。

PLE 显式设置共享专家与任务专属专家，并通过分层门控逐步分离共享与专属信息。适合任务关系复杂、负迁移明显的场景，但参数和调优成本更高。

建议任务分组：点击/有效消费、时长、正向互动、负向反馈。任务数量增加时，先检查标签覆盖、梯度规模和相关性，再决定是否拆专家。

总损失：

\[
\mathcal L=\sum_t\lambda_t\frac{\sum_n m_{nt}\ell_t(y_{nt},\hat y_{nt})}{\max(1,\sum_n m_{nt})}+\lambda_{reg}\Omega.
\]

\(m_{nt}\) 表示标签是否有效且观察成熟。对每个任务按有效样本归一化，避免标签覆盖率改变隐式权重。损失权重控制学习过程，价值融合权重控制线上决策，两者不应混为一谈。

## 7. 位置偏差与卡片吸引力

位置影响被看见和点击。若使用位置特征训练 CTR，服务时需要明确是在预测实际位置下点击率，还是在统一参考位置比较候选。粗暴将所有候选设置为首位可能引入分布外输入。

可以使用展示/检查模型、随机位置实验或倾向加权研究去偏，但需要满足支持集和可识别假设。位置可能与卡片样式和内容类型交互，简单位置系数未必充分。

封面标题与内容语义建议分支建模：前者主要帮助预测选择，后者帮助预测消费兑现。加入点击后秒退和低质量标签，可以抑制仅靠标题吸引点击的内容。

## 8. 推荐基线与消融

先建立 Embedding + DNN + 多任务基线，再依次增加 DCN、DIN、长序列、多任务专家、漏斗结构。每次固定数据时间窗、特征可用性和算力预算，检查 CTR、曝光口径消费、校准及负反馈。

不要同时引入全部结构后只与旧模型比较；无法判断收益来自模型、特征、新数据还是更大计算量。
