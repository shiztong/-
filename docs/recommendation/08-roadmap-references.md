# 08 方案组合、实验路线与公开资料

## 1. 分场景的建议组合

下表是可实施的设计起点，不代表所有业务必须使用相同模型。

| 层级 | 信息流列表页 | 短视频流 |
|---|---|---|
| 召回 | ItemCF + 双塔 + 关注/热点 + 内容语义；分别覆盖点击与有效消费 | 双塔 + 会话序列 + 多兴趣 + 内容语义 + 新视频探索 |
| 粗排 | 轻量交叉，点击与消费多任务，精排蒸馏 | 轻量交叉，有效播放/时长/快划任务，精排蒸馏 |
| 精排底座 | Embedding + DCN/DNN + DIN；长历史有增量时引入检索式序列 | 长短期序列 + 候选 Attention + 特征交叉 |
| 任务组织 | 点击—消费漏斗、时长、互动、负反馈；必要时 MMoE/PLE | 时长分布、快划、完播、互动、负反馈；必要时 MMoE/PLE |
| 重排 | 同屏重复、位置/布局、作者频控、兴趣覆盖 | 连续疲劳、最近反馈、主题节奏、探索 |
| 实时更新 | 可见曝光、点击、消费后回传 | 播放/划走/互动驱动的会话状态 |

跨场景可共享内容编码器和部分用户表征，但标签口径、校准、价值融合与最终重排应分别验证。共享训练时可引入场景 token、场景专属 head 或专家；是否共享更多层由迁移收益而非组织便利决定。

## 2. 分阶段实施

### 阶段 A：可解释且可复现的基线

完成日志、可见曝光、播放有效性、时间一致特征、标签成熟度；建立多路召回、简单多任务排序和规则重排。输出按场景、用户、长度、内容年龄切片的诊断报告。

退出条件不是模型上线，而是能定位损失在哪一层、离线与线上预测是否一致，以及关键反馈能否可靠归因。

### 阶段 B：解决最大的结构性损失

若召回缺失兴趣，优先补召回与语义冷启动；若粗排误杀高价值候选，优先蒸馏和支持集覆盖；若 CTR 上涨但消费变差，优先检查漏斗与融合；若时长受内容长度支配，优先修正目标与校准。

这一阶段只选择有诊断证据支持的模型升级，避免同时堆叠复杂结构。

### 阶段 C：长序列、精细多任务和探索

当基础数据稳定后，引入长历史检索、多兴趣、任务专家、分布时长及有概率日志的探索。每项都需与同等资源基线比较。

### 阶段 D：前沿研究

评估更大规模行为序列模型、生成式检索、统一多模态表征、列表级决策与长期价值。先明确现有系统的瓶颈，再衡量新增复杂度是否值得。

## 3. 前沿模型的关键细节

### 大规模行为序列模型

将内容、动作和上下文转为 token，采用自回归或其他序列训练目标，预训练后迁移到召回与排序。更长历史不等于更有效历史；需要区分训练 token 数、用户覆盖、序列长度和实时新鲜度的贡献。

HSTU 等公开方向研究高效的推荐序列建模与规模化。实际落地要核算长序列计算、缓存更新、稀疏参数存储和在线时延，不能只比较离线指标。

### 生成式召回

把内容映射成离散语义标识序列 \((s_1,\ldots,s_M)\)，训练：

\[
\mathcal L=-\sum_{m=1}^M\log P(s_m\mid H_u,c,s_{<m}).
\]

可用向量量化、残差量化等构造语义 ID，通过约束解码将生成结果映射到有效内容。需解决碰撞、语义编码版本、新内容加入、热门变化、beam search 成本和可推荐过滤。

生成内容标识与直接生成视频内容是不同任务。生成式召回仍需实测精确候选覆盖、多样性和全链路增益，不能仅以 token 预测损失判断优劣。

### 大模型教师与语义增强

用多模态大模型生成主题、实体、质量或语义表征，再蒸馏到在线小模型。弱标注需要抽样人工检查、置信度处理和偏差评估；教师并不天然准确，尤其对低资源语言、细分领域与质量判断。

相比对每个候选实时调用大型语言模型，离线内容理解和小模型蒸馏往往更易控制成本。实时大模型排序是否值得，需要固定预算的对照实验。

## 4. 实验模板

每个实验记录：业务问题 → 机制假设 → 模型/特征变化 → 数据与标签 → 对照预算 → 离线切片 → 在线主指标及护栏 → 长期观察 → 回滚条件。

主指标应预先确定；探索很多指标后只报告显著上升项，会增加误判。长尾任务需给出置信区间和足够观察时间；模型与流量同时变化时难以归因。
