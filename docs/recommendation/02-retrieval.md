# 02 召回模型：双塔、序列、多兴趣与冷启动

## 1. 候选集的组织

建议采用协同、向量、会话、语义、关注、热点、新内容探索等多路组合。通道是否保留取决于独有价值，不取决于模型是否新。

ItemCF 可用共现统计构造相似度：

\[
s(i,j)=\frac{\sum_{u\in U_i\cap U_j}w_u w_{time}(u,i,j)}{(|U_i||U_j|)^\alpha}.
\]

活跃用户降权、时间衰减、热门惩罚和最小支持数能显著影响效果。Swing 类方法进一步利用用户对之间的共同交互结构抑制偶然共现。列表页可按点击与有效阅读建立不同图；视频流可按有效播放、长观看和正反馈建图，避免把所有自动播放当成强正例。

## 2. 双塔的可服务结构

\[
e_u=\operatorname{norm}(f_\theta(x_u,H_u,c)),\qquad
e_i=\operatorname{norm}(g_\phi(x_i)),\qquad
s(u,i)=e_u^\top e_i/\tau.
\]

示例结构：用户离散 Embedding 与统计特征，加上历史序列池化结果，经 MLP 投影到 128 维；内容 ID、作者、主题和多模态向量，经内容塔投影到同一空间。128 是容量实验起点，不是推荐固定值。

内容塔应主要依赖可预计算特征。把当前用户或实时请求交叉放入内容塔，会破坏全局预建索引。用户塔可在请求时读取最新状态；内容向量按新增、更新和过期策略维护索引。

归一化使得相似度主要表达方向；不归一化时向量范数可能承载热度和置信度。两种方式要分别验证，并确保训练、索引、检索使用同一种距离定义。

### 对比损失与负样本

\[
\mathcal L_{ret}=-\log\frac{\exp s(u,i^+)}{\exp s(u,i^+)+\sum_{j\in N_u}\exp s(u,j)}.
\]

这首先是一个对比目标。只有在明确采样分布和修正方式时，才能进一步解释为全库 softmax 的近似。

- 批内负例：便宜，分布偏向训练正例频率；同一内容的重复和多个正例需要 mask。
- 全库随机负例：覆盖广，但大量样本过于容易。
- 曝光未消费：更接近决策边界，但受旧策略和位置影响。
- 困难负例：从当前模型近邻中抽取，区分力强，也更容易包含假负例。

可采用已知采样概率的 sampled-softmax 修正；具体 \(\log q(i)\) 修正应遵循采用的采样估计器，不能对任意混合负例机械减去词频。困难负例宜渐进引入，并过滤同主题强相关内容中的潜在正例。

### 场景化正例

列表页可建立点击召回与有效消费召回两个目标，或者在共享表征上建立不同投影头。视频流可区分有效播放、长观看与关注目标。样本权重不宜无限随时长增长，否则长视频和重度用户会支配训练。

## 3. 序列召回

历史行为 token：

\[
z_t=W[e_{item_t};e_{action_t};e_{topic_t};\phi(T_t,D_t);e_{gap_t}]+e_{position_t}.
\]

经因果 Transformer 得到 \(h_t\)，用最后状态或池化状态预测后续内容。自回归训练可使用：

\[
\mathcal L_{seq}=\sum_t-\log P(i_{t+1}\mid z_{\le t}).
\]

SASRec 是典型技术脉络。推理只允许使用当前请求前的事件；训练采用什么屏蔽方式，线上就必须有与之相容的信息条件。

列表页的曝光序列与点击序列应区分：曝光表达机会，点击表达选择。视频流可将滑走、观看、复播编码为不同反馈；不建议把负反馈内容当成与点赞完全相同的 token。

长序列成本可通过分层历史、时间桶压缩、离线长期记忆与在线短期序列结合降低。KV cache 只有在模型结构、用户状态隔离、时间编码和状态失效规则正确时才能复用。

## 4. 多兴趣召回

将用户表示为 \(K\) 个向量：

\[
e_u^{(k)}=\sum_t\alpha_{kt}v_t,\quad
\alpha_{kt}=\operatorname{softmax}_t(q_k^\top Wz_t),\quad
s(u,i)=\max_k (e_u^{(k)})^\top e_i.
\]

可采用动态路由、可学习查询或其他兴趣抽取模块；MIND、ComiRec 提供了代表性路径。上式是便于理解的一种实现，并非所有多兴趣模型的统一公式。

训练中需防止多个兴趣头塌缩到同一热门主题，可使用兴趣差异约束、覆盖正则或适当负载均衡。但强迫兴趣头完全正交可能伤害自然重叠兴趣。

在线分别检索每个兴趣向量，合并去重，再按兴趣置信度、活跃度与探索预算分配候选数。总检索成本随兴趣数增长，必须比较在同等预算下是否优于单向量模型。

## 5. 内容与多模态冷启动

内容塔可先编码标题/字幕、封面、关键帧、音频，再融合：

\[
e_i=g([e_{id};P_t e_{text};P_v e_{video};P_a e_{audio};m]),
\]

其中 \(m\) 为模态缺失 mask。使用模态 dropout、ID dropout 或内容分支辅助损失，降低模型过度依赖已有内容 ID 的风险。

可对齐内容向量与协同教师向量：\(\mathcal L=\mathcal L_{ret}+\lambda\|e_i^{content}-\operatorname{sg}(e_i^{teacher})\|^2\)。教师对低曝光内容也可能不可靠，因此应按置信度筛选或降权，而非把所有教师向量当成真值。

语义相似不等于用户愿意消费。语义召回需要用实际反馈校准，并配合新内容探索，才能从“内容是什么”转向“谁会喜欢它”。

## 6. 索引、融合与验收

工程步骤：训练内容塔 → 全量编码 → 建 ANN 索引 → 增量更新 → 请求编码用户 → 各通道检索 → 去重过滤 → 粗排。索引和用户模型需要版本兼容；更新一侧而不更新另一侧可能造成向量空间失配。

离线分别测精确检索的业务 Recall@K 与 ANN 相对精确检索的近邻召回率；前者衡量模型，后者衡量近似检索损失。线上评估通道独有曝光、有效消费、新内容覆盖、延迟和资源成本。

可先用固定配额建立基线，再按通道边际收益调整。通道内相似度不宜跨模型直接相加；来源、排名、多路命中和分数可作为粗排特征。
