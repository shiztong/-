# 01 场景、标签与优化目标

## 1. 列表页：曝光 → 点击 → 消费

列表页用户先比较卡片，再进入内容。标题、封面、位置决定点击机会，正文或视频决定点击后价值。

建议分别记录接口下发、进入可视区、可见持续时间、点击、详情页消费。未进入可视区的内容缺少选择机会，不能直接当作曝光未点击负例。曝光去重、重复点击、返回列表的归因规则必须固定。

令 \(C\) 为点击，\(Q\) 为点击后有效消费，并定义 \(Q\subseteq C\)。则：

\[
P(Q\mid E,u,i,c)=P(C\mid E,u,i,c)P(Q\mid C,E,u,i,c).
\]

这个恒等式要求两个模型的点击、曝光与消费事件口径兼容。如果有效播放可以发生在卡片自动播放中，就不能套用必须先点击的漏斗。

时长任务同样有两种口径：

- 条件时长 \(\mu_C=E[T\mid C,E,u,i,c]\)：未点击样本没有详情页时长标签。
- 曝光期望时长 \(\mu_E=E[T\mid E,u,i,c]\)：在定义未点击详情消费为零时，\(\mu_E=p_C\mu_C\)。

模型已经预测 \(\mu_E\) 时，再乘 CTR 会重复折损。

### 标签设计

| 任务 | 正样本 | 负样本/观察集 | 风险 |
|---|---|---|---|
| 点击 | 可见后点击 | 可见但未点击 | 位置和封面偏置 |
| 有效消费 | 满足阅读/播放质量规则 | 依全空间或点击空间定义 | 条件分布不同 |
| 秒退 | 点击后极短消费 | 有消费机会的点击样本 | 加载失败可能伪装为不喜欢 |
| 收藏/分享/关注 | 指定窗口内发生 | 标签窗口成熟样本 | 稀疏和延迟 |
| 显式负反馈 | 不感兴趣、屏蔽、举报 | 可见且观察完成样本 | 不发生不等于满意 |

有效消费阈值应按内容形式设计，例如阅读与视频不能机械共享固定秒数。阈值标签易优化但会丢失连续价值，宜与连续时长、满意度信号联合使用。

## 2. 视频流：播放 → 停留/滑走 → 深度消费

自动播放并不代表主动选择，因此不能照搬 CTR。应区分预加载、真正展示、起播成功与实际可消费状态。

快速划走标签可写成：

\[
y_{skip}=\mathbf 1(T<\tau,\ \text{用户主动滑走且播放可用}).
\]

\(\tau\) 是待验证的业务阈值，不是行业统一常数。网络失败、退后台、系统中断应有独立标记，不能全部解释为兴趣负反馈。

视频长度 \(D\) 同时影响可观看时长与完播机会。至少联合分析：绝对时长 \(T\)、首轮观看比例、完播、复播、快划、主动互动。超长视频、短视频与图文转视频需要分别检查。

## 3. 多目标预测与决策分离

预测层输出 \(p_Q,\mu_T,p_{like},p_{follow},p_{skip},p_{dislike}\) 等；决策层对其进行校准、变换和融合：

\[
V=\sum_k w_k(u,c)g_k(\hat y_k)-\sum_j\lambda_j(u,c)r_j.
\]

这里的 \(g_k\) 用于量纲处理和边际价值变换，例如时长可以具有递减收益。\(w_k\) 应受业务约束与实验验证；由网络预测权重也不自动保证业务目标正确。

约束可以表达为平均负反馈不超过阈值、重复率不超过预算、新内容获得最低探索机会等。安全准入和强屏蔽通常应直接过滤，不能允许高预测时长抵消。

## 4. 短期指标与长期指标

短期目标可提供密集训练信号，长期回访与留存用于实验验收。直接把“明天是否回来”复制给今天每条曝光，会产生严重归因噪声：用户本身的活跃倾向、其他内容、推送等都在影响结果。

长期建模需要明确动作、时间跨度、混杂因素和探索支持。阶段初期更稳妥的是：优化经过验证的短期代理目标，同时使用长期对照组监测留存、满意度和供给变化。

## 5. 评估切片

必须同时按场景、新老用户、活跃层级、内容年龄、内容长度、类目、网络与设备切片。总体时长上升可能只是长视频流量占比变大；总体 CTR 上升也可能只是位置结构发生变化。

不要为了控制混杂而无差别控制决策后变量。分析时要先画清变量的时间顺序和因果关系。
