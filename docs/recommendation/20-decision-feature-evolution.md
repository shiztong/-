# 20 重排、特征、训练与评估的发展路标

## 1. 重排：从规则兜底到组合决策

### D0：准入、去重、频控

安全、版权、用户屏蔽、过期和基础重复控制属于可推荐资格与强约束。部分过滤应尽早完成，最终决策还需防漏；不能依赖高时长抵消不允许展示的内容。

这是长期保留的基础能力，不会因为学习式重排出现而消失。

### D1：相关性与多样性的显式权衡

MMR、主题覆盖、作者频控及约束优化，从单条最高分转向组合收益。DPP 类路线用质量与相似度核表达集合多样性，是另一种代表研究思路；核构造、正半定性与大候选计算影响可用性，不是直接换一个公式即可上线。

列表页关心同屏重复、位置和卡片组合；视频流关心连续主题、作者和相似视频。多样性不是最大化不相关内容，强兴趣用户连续消费同主题可能是合理需求。

### D2：学习式列表交互

候选经注意力、图或其他交互网络建模相互竞争和互补，再输出相对价值或位置分配。需要区分训练中的 listwise loss 与模型输入中真实发生的列表交互。

旧排序决定展示位置与被点击机会，学习式模型很容易模仿旧顺序。候选未展示不等于真实负例；位置实验、采样和偏差处理需匹配可观察数据。

### D3：会话状态、疲劳与探索

下一条价值依赖近期反馈；状态包含快划、主题密度、重复曝光、会话时长等。对尚未展示的预取列表，只能更新“计划组合”的重复状态，不能生成虚假用户反馈更新兴趣。

探索从固定预算随机抽样，发展到分层质量估计、contextual bandit 和不确定性驱动。前提是定义反馈、风险与策略概率；模型分数接近 0.5 不天然表示认知不确定。

### D4：长期与多主体决策

研究延迟满意度、回访、创作者供给和不同用户群体验。多主体目标可能冲突，生态目标不能只写成无成本的额外奖励。

受约束 RL 是候选方向，不是默认终点。先在混排配额、探索预算等较小动作空间验证；离线策略评估需要支持集和可靠概率，用户模拟器结果不当作真实收益。

## 2. 用户特征：从标签画像到多尺度记忆

| 路标 | 表达方式 | 损失与挑战 |
|---|---|---|
| U0 属性与统计 | 静态属性、类目/作者计数 | 难区分曝光机会与偏好 |
| U1 稀疏表征 | 用户ID、作者/主题 Embedding、显式交叉 | 低频用户、OOV、记忆过拟合 |
| U2 多行为序列 | 点击/消费/互动/负反馈与时间编码 | 行为语义、标签延迟、长度成本 |
| U3 长短期/会话 | 分支编码、门控、候选相关激活 | 重复记忆、兴趣冲突、实时性 |
| U4 长期记忆与统一表征 | 压缩/检索记忆、共享行为底座 | 失真、状态版本、隐私与维护成本 |

未来重点是保持低频兴趣，同时对新反馈快速反应。用户记忆应有可删除、可过期和可追溯机制，不无限保存历史。

## 3. 内容特征：从 ID 到消费语义

`内容ID/作者/类目 → 文本与封面 → 视频/音频/字幕/OCR → 多模态对齐 → 内容-行为共同表征与教师蒸馏`。

早期主要靠已有反馈记忆；语义编码扩展到新内容，统一多模态帮助处理复杂表达。但内容“是什么”和用户“是否想消费”仍有距离，需要行为监督和探索闭环。

列表页应保留封面标题与实际内容的不同分支，识别吸引力与兑现落差。视频流应区分开头吸引、持续内容价值和播放质量。模型不能把所有高停留都解释为满意。

未来研究包括时序结构、细粒度实体、内容更新、新事件与语言/领域泛化；每条内容编码的成本和新内容上线延迟同样是指标。

## 4. 上下文和交叉：从固定字段到状态条件化

先使用时段、入口、设备/网络和位置；再加入会话进度、最近反馈、预取状态与候选列表关系。显式交叉从用户×主题、用户×作者发展到历史×候选、候选×已选内容和场景条件化专家。

未来可以研究更统一的 context token 和门控，但信息必须在决策时已知。会话最终时长、候选未来消费和请求后统计不能进入输入。模型更大时泄漏更容易被利用，不会自动得到缓解。

## 5. 训练与服务：算法升级的隐含依赖树

```text
时间一致样本 + 标签成熟窗口 + 数据质量
  → 周期训练 + 可复现配置 + 模型/特征版本
  → 批流特征 + 用户状态实时化 + 增量内容索引
  → 稀疏参数生命周期 + 分布式训练 + 增量学习
  → 请求级共享 + jagged计算 + 低精度/kernel + 蒸馏
  → 质量/成本/新鲜度联合扩展与自动回滚
```

这些不是必须在同一时间全建设。基础必须先有；实时全参数训练、定制 kernel 和大型参数服务取决于规模与瓶颈。

Monolith 的公开说明支持无碰撞 Embedding 与实时学习，提示稀疏参数管理的重要性，但引入框架需要兼容性和团队能力评估。HSTU 公开系统扩展提示模型、候选共享和硬件联合设计，不能只复制注意力公式。

更新用户状态、更新新内容索引、更新 Embedding、重训全模型是四条不同链路，应分别定义延迟与回滚。把它们统称实时推荐会掩盖瓶颈。

## 6. 评估：从单一 AUC 到可识别的长期价值

| 阶段 | 主要能力 | 仍需防止 |
|---|---|---|
| E0 离线模型指标 | AUC、LogLoss、Recall、NDCG | 时间泄漏、全局平均掩盖切片 |
| E1 预测与决策一致 | 校准、分层误差、同预算比较 | 离线正例受旧策略影响 |
| E2 在线随机实验 | 稳定分桶、A/A、功效、护栏 | 多重检验、重复偷看、场景溢出 |
| E3 长期与生态 | 回访、满意度、供给质量、长期对照 | 归因错误、奖励投机 |
| E4 因果与策略评估 | 随机探索、IPS/DR、保守策略评估 | 支持集不足与极端方差 |

离线 NDCG、线上时长、留存和货币收益不是一条确定映射链。每次技术升级都需要自己的证据；实验本身也必须持续升级。

## 7. 未来系统形态

更可能形成“共享内容/行为表征 + 场景专属决策 + 实时状态 + 可控探索 + 可审计实验”的组合，而不是一个无边界模型。即使部分召回排序统一，准入、状态、版本、成本和实验仍需独立治理。
