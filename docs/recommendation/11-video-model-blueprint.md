# 11 视频流模型实现蓝图：会话编码与观看分布

本文给出可独立实现的短视频精排方案。网络规模和时间边界是示例，不声称是某家公司线上标准。先预测首轮观看，再独立处理复播，避免把物理长度和重复消费混为一谈。

## 1. 先建立消费状态机

```text
预加载 → 真正展示 → 可播放 → 首轮观看
                         ├→ 主动划走/退出
                         ├→ 播放到视频结尾
                         └→ 日志窗口结束但仍在观看
播放到结尾 → 自动循环/主动复播 → 额外观看
```

主动划走是已观察的首轮结束；自然播放结尾是首轮完播；日志观察窗口结束时仍观看是删失。退后台、系统暂停等是否代表会话结束应按产品埋点定义，不能随意归类。

定义首轮观看 `T1∈[0,D]`；总观看 `Ttotal=T1+Textra`。没有复播机会不等于用户不愿复播；复播标签要明确是在全部有效起播空间预测，还是在已完播条件空间预测。

## 2. 用户与候选编码

### 会话分支

每个历史行为 token 包含：内容表征 64 维、行为类型 8 维、时间间隔 8 维、观看比例/时长/长度等数值投影 16 维，合计 96 维，再投影至 128 维。

最近 `Ls=50` 条行为经过两层 Transformer，4 头、FFN 512，得到 `[B,50,128]`。输入仅含请求前已观察反馈。完整历史聚合可使用双向编码；若逐位置 next-item 辅助训练，则需要因果 mask。

输出最近有效状态 `hS:[B,128]`。序列已按时间排序且 padding 方向固定，不能简单取张量最后一行代替最后有效位置。空序列使用独立路径。

### 长期分支与候选相关历史

长期主题/作者统计与较早行为池化投影到 `hL:[B,128]`。候选多模态向量经 `256→128` 投影得到 `q`，作为 query 对会话历史做多头 Attention，得到 `hI:[B,128]`。

门控 `g=sigmoid(MLP([hL;hS;context]))`，融合 `hU=g*hS+(1-g)*hL`。再拼接：

```text
hU 128 + hI 128 + candidate q 128 + static/cross 128 = 512
→ Linear(512,256) → LayerNorm → GELU
→ 多任务专家或共享主干 → 各任务 head
```

先使用共享主干验证任务口径，再比较 MMoE/PLE。不要在标签尚未稳定时引入大量专家掩盖数据问题。

## 3. 基线一：时长区间 softmax

设首轮时长网格为 `b=[0,1,3,5,10,20,40,80,...]` 秒，输出 `K` 个桶的概率。对片长较短的内容，需要使超出片长的首轮时长区间不可能发生，并将视频结尾的完播事件妥善归入可达桶。

如果直接输出全局桶再硬屏蔽，也会改变不同长度内容的归一化结构；应在训练和推理一致应用，并分别检查短视频校准。尾部开桶不允许直接选取无限中点。

该方案易实现，但完播与发生在相同桶内的提前退出会被混合。若要精确区分，可采用以下基于进度的 hazard 模型。

## 4. 基线二：首轮观看进度 hazard

将进度 `[0,1]` 分为 `K=20` 个区间，`r_k=k/K`。定义：

\[
h_k(x)=P(T_1/D\in[r_k,r_{k+1})\mid T_1/D\ge r_k,x),
\quad k=0,\ldots,K-1.
\]

`h_k` 表示在该进度区间内提前终止首轮观看的条件概率。到达视频结尾的概率作为单独的剩余质量，而不是再增加一个“结尾退出 hazard”。

网络 head：`256→64→K` logits，`h=sigmoid(z)`。到达边界的生存概率和各区间结束概率：

\[
S_0=1,\quad S_k=\prod_{j<k}(1-h_j),\quad
p_k=S_kh_k,\quad p_{complete}=S_K.
\]

它们满足 `sum(pk)+pcomplete=1`。这既给出提前终止分布，也给出完播概率，结构上保持一致。

### 标签与似然

提前结束于区间 `m`：

\[
L_{exit}=-\sum_{j<m}\log(1-h_j)-\log h_m.
\]

完整首轮播放：

\[
L_{complete}=-\sum_{j<K}\log(1-h_j).
\]

若观察仅持续到 `r_c`，之后不可见，采用只计完整已观察区间的近似：

\[
L_{censored}=-\sum_{j<c}\log(1-h_j).
\]

桶内删失不说明整个桶已存活，不能把当前桶也记作存活；该离散近似会损失桶内信息。若桶内精度重要，可以使用更细网格或连续时间 hazard。

完播判定需要真实结束事件，而不是仅凭浮点 `T1/D>=1`。日志误差和播放器时间计量会导致接近结尾的样本误分。

### 稳定的实现形式

```python
# z:[B,K]，FP32 下累计；valid_interval:[B,K]
log_survive = -softplus(z)       # log(1-sigmoid(z))
log_exit = -softplus(-z)         # log(sigmoid(z))

# 对所有确定已完整存活的区间计入生存项
loss = -(log_survive * survived_mask).sum(-1)
# 只有真实提前结束样本有 event interval
loss -= (log_exit * exit_onehot).sum(-1)
loss = weighted_masked_mean(loss, sample_weight, label_valid)
```

`survived_mask` 对提前结束样本只取 `j<m`；完播取全部；删失取确定存活的完整区间。`exit_onehot` 对完播/删失全零。不要同时对完播样本再添加最后一桶退出事件。

## 5. 从分布到消费指标

使用区间代表进度 `mu_k=(r_k+r_{k+1})/2`，近似：

\[
\hat E[T_1|x]\approx D\left(\sum_kp_k\mu_k+p_{complete}\right).
\]

这是桶内中点近似，不是精确期望。可以预测桶内残差或使用更细网格提升精度。首轮时长期望应在 `[0,D]` 内。

任意秒数阈值 `t` 对应进度 `t/D`；可使用边界的生存概率，桶内则需显式插值假设。`t>D` 时首轮到达该阈值的概率是零。短视频不能因为无法达到 10 秒就被当作兴趣差，因此有效消费标签与决策仍需长度感知。

该模型的早期秒数精度取决于长度：对 200 秒内容，5% 是 10 秒，难以区分 1 秒快划。可以改用绝对秒数 hazard，或设计早期按秒、后期按进度的条件网格；每个样本的边界需单调，并在训练和推理一致使用。不能期待固定进度网格自动解决所有快划问题。

## 6. 复播与总观看

单独预测全起播空间的复播事件概率 `pR`，并仅在真实复播样本上训练额外时长的条件分布，得到 `muExtraGivenR`：

\[
E[T_{total}|x]=E[T_1|x]+p_R E[T_{extra}|R,x].
\]

该分解利用期望可加性，不要求首轮时长与额外时长独立。如果 `pR` 预测的是完播条件下的复播概率，则需要再乘完播概率，前提是复播事件确实必须先完播。

自动循环和主动复播可拆成任务或特征，但要避免把播放器设计带来的循环直接当作满意度。若额外时长仍有删失，应按其观察机制建模，而不是记录当前值为最终值。

## 7. 快划、互动与负反馈辅助任务

快划 head `256→32→1`，标签为可播放后主动快速划走。与 hazard 分布推导的早期结束概率对齐，有助检查标签是否自洽；若两者定义不同，不应强行施加一致性损失。

点赞、分享、关注分别使用二元 head。显式不感兴趣/举报独立建模；播放失败独立诊断，不和兴趣负例混用。

\[
L=\lambda_H L_{hazard}+\lambda_S L_{skip}
+\lambda_R L_{replay}+\lambda_X L_{extra}
+\sum_a\lambda_a L_a.
\]

各项先按有效样本归一化。大量完播会使 hazard 频繁收到“继续观看”梯度，需按长度和完成率检查；不能为了平衡就随意重采样却不校准概率。

## 8. 长度条件质量与价值融合

一组长度条件基线 `m(D,topic,context)` 可产生相对质量指标。模型可以同时输出首轮期望、完播、复播和长度条件表现，但相对分数不是去偏后的真值。

决策示例包含首轮消费效用、复播价值、关注和负反馈成本。若使用递减效用 `g`，建议从分布计算：

\[
E[g(T_1)]\approx\sum_kp_kg(D\mu_k)+p_{complete}g(D).
\]

这不同于 `g(E[T1])`。对于时长效用、快划惩罚和完播奖励同时存在的方案，需要检查重复奖励是否符合业务定义。

长期目标仍通过实验验收。单纯提高预测时长不能证明用户更满意，也不能证明回访增加。

## 9. 必做数学与工程检查

- 任意 logits 下提前结束概率加完播概率约为 1；生存概率单调不增。
- 全部 `h≈0` 时应近似全部完播；`h0≈1` 时应近似首桶结束。
- 同样特征下首轮期望不超过片长；复播的额外时长非负。
- 删失样本不得产生虚构退出梯度；仅存活区间有监督。
- 未发生在请求前的行为不得进入会话编码；空历史与全 padding 不出现 NaN。
- 半精度训练中 log/累积乘积用稳定形式；长网格优先累计 log-survival。

## 10. 分场景实验与故障诊断

固定特征与算力，对比时长回归、区间 softmax、hazard；分别报告不同长度的时长校准、快划、完播、互动、负反馈与在线收益。

若 hazard 离线很好但线上恶化，优先排查：删失误记负例、播放失败混入快划、长视频首桶过粗、复播定义变化、用户状态更新延迟。若会话编码只对老用户有效，检查新用户空历史路径与用户 ID 依赖。

对连续快划用户评估下一条恢复，不只看全体平均；对新内容评估前几轮反馈与扩大分发后的校准变化。可播放视频和所有下发视频是不同分母，实验报告必须写清楚。
