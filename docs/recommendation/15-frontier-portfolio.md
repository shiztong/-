# 15 前沿规划：按瓶颈与资源收益选择研究组合

## 1. 投资顺序

前沿不等于所有模型一起上。建议把成熟链路与研究链路分开预算：主线优先补数据、实时状态、粗精排一致性；研究线只保留少数可证伪方向。下列收益为机制假设，真实百分比一律待本项目实验。

| 方向 | 优先条件 | 预期收益来源 | 最大失败风险 | 默认决策 |
|---|---|---|---|---|
| 用户状态实时化 | 兴趣快速变化且状态滞后 | 更快利用反馈、减少疲劳 | 反馈误归因、噪声放大 | 先建设与验证 |
| 召回/粗排蒸馏 | 精排优质候选在前级丢失 | 提高同预算有效候选覆盖 | 复制教师偏差 | 有证据时优先 |
| 多模态语义与新内容 | 新内容和长尾贡献受限 | 冷启动、主题泛化 | 语义相关但不爱看 | 中短期重点 |
| 长序列/HSTU | 短序列覆盖不足且预算允许 | 长期兴趣、复杂行为交互 | 成本、新鲜度和缓存失配 | 受控研究主线 |
| 生成式召回 | 语义编码与大规模序列已较成熟 | 新候选组织、联合生成 | 新内容 ID、解码延迟和过滤 | 旁路，保留 ANN |
| 列表级/会话级优化 | 独立打分导致同屏竞争或连续疲劳 | 组合互补与序列体验 | 标签偏差、状态不充分 | 先约束重排再学习 |
| 长期价值/RL | 随机探索、状态和长期目标可靠 | 延迟满意度与供给改善 | 反事实不可识别、奖励投机 | 最后进入 |

## 2. HSTU 与长序列：模型和推理共同设计

### 结构级差异

研究 HSTU 的示意计算可写作：

\[
[U,V,Q,K]=\phi(W\,LN(X)),\quad
A=Mask\odot SiLU(QK^\top+B_{rel})/N,
\]
\[
H'=X+W_o\big(U\odot LN(AV)\big).
\]

这里省略多头重排、dropout、jagged 存储和实现可选分支；`Brel`、归一化与 `N` 的定义必须对照 [13 的固定源码](13-industry-evidence.md)，不能用普通 softmax Attention 偷换。SiLU 权重不要求和为 1，也不是概率分布；幅度信息与门控共同作用。

### 三步实验而非一次“大模型升级”

1. 等数据、等长度、近似等训练/服务预算：MLP/DIN、SASRec、HSTU 对照，区分结构收益。
2. 固定结构，扩历史长度，报告低频兴趣增益与实时性；分离长度和新鲜度贡献。
3. 固定质量目标，评估请求内候选共享、jagged/半局部计算和低精度投影，获取成本前沿。

shared history / target-aware 方法可以减少重复历史编码，但候选之间的 mask 必须符合推理条件：候选不得通过其他候选的未来反馈获得信息。多候选一起打分不等于允许目标标签进入 Attention。

### 缓存约束

时间相对偏置、候选相关层、窗口淘汰、用户状态乱序都会影响 cache 是否有效。官方当前 README 明确部分 Ultra 集成没有 cached incremental decoding，不能将其作为现成可上线特性。先做缓存与全量重算输出一致性，再讨论性能收益。

**Go**：同预算离线和分层校准有增益，完整服务达 SLO，线上主指标过经济门槛。**No-go**：仅更大模型更好、增量收益低于新增算力，或模型更新导致状态不可可靠缓存。

## 3. 多模态理解与语义冷启动

流程：离线视频/文本/音频教师 → 结构化主题/质量与向量 → 小模型内容塔 → 冷启动探索 → 新反馈更新。

训练目标可组合协同监督、跨模态对齐与教师蒸馏，但必须按内容年龄评估：训练中见过内容的高分不证明新内容有效。作者划分和内容时间划分可进一步检测记忆、近重复泄漏。

成本包含每条新增内容编码时长、GPU 离线批量利用率、重编码频率和向量索引刷新；不是只计算在线增加一层投影。强模型教师错误和时事知识滞后需要人工抽检与版本管理。

**Go**：零/低曝光内容在受控探索中获得有效消费增益，且整体负反馈不恶化。**No-go**：只改善语义检索指标、优质新内容没有真实消费提升。

## 4. 生成式召回：先做候选增量通道

语义 ID 可以由 RQ 类量化生成多个离散码，再自回归预测码序列。必须维护 ID→可推荐内容集合、碰撞消解、版本化和动态新内容登记。

解码可使用 trie 约束与 beam search，之后执行内容准入和去重。beam 数量增加既提高覆盖也增加延迟；比较时应保持最终候选数与总服务预算相同。

训练 token loss 下降不能证明 Recall 上升，更不能证明整体收益。对照应至少包括：成熟 ANN 通道、同预算序列召回，以及 ANN+生成通道的增量贡献。已有通道检索到相同内容不算独有覆盖。

本轮未核验到 OneRec 可用的官方代码链接，因此不引用其收益。TIGER 等论文可作技术线索，未在本轮复现。生成式召回不取代确定性过滤、版本发布或实验系统。

## 5. 价值对齐与长期优化

先进行多目标校准、受约束重排和探索概率记录，再研究长期价值。奖励应覆盖满意度、负反馈与供给，不宜只用会话时长；用户合理退出不能自动当作失败。

选择较小动作空间，例如各通道配额、探索率或内容组合，而非直接在数千万条内容上离线 RL。OPE 必须报告支持集、权重分布和有效样本量；仿真收益不作为上线收益。

**Go**：随机化支持与长期对照完整，保守策略在受控线上实验提升目标。**No-go**：仅模拟器或旧日志估值上升，结果依赖极端重要性权重。

## 6. 每个方向的停止机制

研究开始前填写：假设、负责人、最大训练预算、服务成本上限、数据依赖、首个可证伪实验和停止时间。两个阶段均未超过匹配预算基线时，应停止扩大模型，回到错误分析。

模型参数、历史长度、训练样本和负例数至少是四个独立扩展轴，不能同时翻倍后将全部收益归于某个新架构。实验结论应包含失败切片与资源占用，不只列最佳单点。
