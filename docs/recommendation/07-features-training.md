# 07 特征、样本与训练系统

## 1. 用户特征：分层保存兴趣

| 层级 | 特征与编码 | 更新要求 | 主要用途 |
|---|---|---|---|
| 基础/生命周期 | 活跃层级、注册时长、设备、合法可用地域 | 按变化更新 | 冷启动、分层校准 |
| 长期兴趣 | 主题/作者分布、长期序列、聚类兴趣向量 | 批流结合 | 稳定偏好和长尾兴趣 |
| 中短期兴趣 | 多窗口消费分布、最近行为序列 | 分钟级或更快，按业务要求 | 兴趣变化 |
| 当前会话 | 最近观看/点击/快划、连续主题、会话进度 | 请求级或事件级 | 即时分发 |
| 负向约束 | 屏蔽、不感兴趣、重复曝光 | 尽快生效 | 过滤与降权 |

这里的更新频率是设计需求，不保证底层系统天然满足。必须测量端到端事件到特征可见的延迟。

一种衰减兴趣统计：

\[
I_{u,k}(t)=\sum_{e<t}\exp(-(t-t_e)/\tau)\,w(action_e)\,q_e\,\mathbf1(topic_e=k).
\]

不同动作权重和 \(\tau\) 应通过验证选择。曝光量决定用户获得多少选择机会，因而应同时保留曝光与消费统计；只累计消费会强化旧系统的供给倾向。重复行为、机器人和异常长停留需要清洗。

## 2. 内容特征：静态语义与动态反馈分离

### 静态及低频变化

内容 ID、作者、发布时间、长度、形式、语种、地域、类目、主题、实体、文本/视频/音频表征、质量及安全信号。

列表页额外关注标题、封面与实际内容的一致性；视频流关注首段表达、时序语义、音画质量及复播结构。内容风险信号应有明确的准入与分发规则。

### 动态反馈

曝光量、点击、有效消费、时长分布、快划、互动和负反馈，按多个时间窗口、场景、人群分别统计。

二元率可用平滑：

\[
\hat p=\frac{s+\alpha}{n+\alpha+\beta}.
\]

\(\alpha,\beta\) 来自合理先验或历史拟合。它降低小样本方差，但不能消除曝光人群、位置或旧策略造成的偏差。新内容缺失统计应有明确 missing mask，而不是伪装成表现差。

保留内容年龄、统计样本量、统计窗口和更新时间，使模型区分“反馈差”和“尚未获得足够反馈”。

## 3. 上下文与交叉特征

上下文包括场景、入口、小时、工作日、设备/网络、会话进度、近期反馈以及列表布局。

交叉可分为：

- 用户—作者：关注关系、历史有效消费、最近曝光与负反馈。
- 用户—主题：长期偏好、当前会话偏好、主题饱和程度。
- 用户—长度—时间：在当前情境下的长度偏好。
- 历史—候选：语义相似、作者关联、正负行为匹配。
- 候选—已选列表：重复、互补、覆盖增量。

在线大规模交叉表需要控制基数、稀疏性、TTL 与冷热分层。哈希碰撞会把不同语义混合，不能只检查内存节省。

## 4. 数据样本契约

一条训练样本至少明确：

```text
request_id / impression_id / event_time / scene
user_id / item_id / session_id / actual_position
candidate_source / model_version / feature_version
feature_snapshot_or_asof_reference
labels / label_window_end / label_validity_mask
sampling_probability_or_weight
```

日志中的用户标识应符合最小化、权限控制和保留周期要求。不要为了调试将个人数据写入公开仓库。

每个任务记录事件单位：按请求、按曝光、按播放还是按用户日。如果同一条内容一天多次曝光，标签不能无条件复制到所有曝光。

## 5. 时间一致与泄漏检查

样本时间为 \(t\)，特征必须是决策时可获得的版本，而不是离线重算后回填到过去的最新值。

例如 10:00 的曝光不能使用 10:05 才产生的内容 CTR；即使它被写在“当天统计”字段里，也构成泄漏。事件时间早于请求但尚未到达在线系统的迟到事件，也不一定是当时可用特征。

建议记录事件时间、接收时间、特征生效时间。离线 as-of join 与线上实际可见性要匹配；只有按事件时间截断仍可能高估线上效果。

训练/验证/测试按时间切分，并等待相关标签成熟。特征变换、词表、归一化和教师模型训练都应遵守切分边界。严格冷启动评估还需按用户或内容是否在训练中出现进行独立切片。

## 6. 负采样、权重与概率恢复

假设所有正例保留，负例以概率 \(r\) 独立保留。若模型学习采样分布下概率 \(p_s\)，理想条件下：

\[
p=\frac{r p_s}{1-p_s+r p_s},\qquad
\operatorname{logit}p=\operatorname{logit}p_s+\log r.
\]

适用前提是该抽样机制正确且模型概率可用。若负采样依赖用户、内容或难度，应使用对应采样概率并检查支持集，不能只用一个全局常数。

也可用逆采样概率加权训练全空间目标，仍需检查方差与模型拟合。召回的对比学习分数与 CTR 概率是不同对象，不套用同一恢复公式。

## 7. 多任务优化与训练稳定性

先排查任务有效样本数、损失量纲和梯度规模，再使用 GradNorm、梯度投影等自适应方法。不同任务在共享层的梯度夹角可辅助诊断冲突，但一次观测不能说明任务应永久拆分。

稀疏参数与稠密参数可以采用不同优化器、学习率和正则；Embedding 的低频更新、参数淘汰和新增 ID 初始化需统一定义。过强的频率正则可能伤害长尾，过弱又可能过拟合。

持续训练要防止只吸收最近反馈而遗忘长期兴趣，可以使用历史重放、时间混合采样和模型版本回滚。发生分布变化时同时检查数据质量、策略变化和真实兴趣变化。

## 8. 评估与生产闭环

分类检查 LogLoss、校准与 AUC/GAUC；时长检查分层误差、总量校准和分布；排序检查请求内价值排序与最终在线收益。

用户内只有单一标签时无法计算该用户 AUC，GAUC 实现应明确剔除规则与加权口径。分桶校准应同时看样本量，避免小样本噪声被解释为系统性误差。

线上监控输入缺失率、OOV、特征年龄、预测分布、专家门控、延迟与降级；业务监控有效消费、负反馈、回访和供给生态。数据、模型与策略版本共同决定实验解释，不应只记录模型名。
