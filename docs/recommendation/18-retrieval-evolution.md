# 18 召回的发展路标：从共现到生成

本章说明技术脉络；当前实施统一见 [召回总路标与 31 项交付台账](../recall/README.md)。其中 SDM/序列为 S1/S2，位置消偏为 B1/B2，与采样、ANN、融合及实验按同一套状态和依赖验收；本轮遗漏与推进顺序见 [最终实践审查](../recall/BEST_PRACTICE_REVIEW.md)。

## 1. R0 → R1：规则、共现与潜在因子

**起点**：热门、关注、类目和地域规则解决冷启动与可控供给，但无法精细个性化。UserCF 利用相似用户，ItemCF/Swing 利用用户历史触发相似内容；矩阵分解把用户与内容映射到潜在空间：`score(u,i)=p_u^T q_i`。

**重要变化**：从人工定义相关变成行为驱动相关；矩阵分解又把离散共现压缩成可泛化表征。隐式数据中未交互不等于不喜欢，负例、置信度和曝光机会成为关键。

**为什么继续演进**：新内容无交互、用户多兴趣混在单一表示中、上下文难进入、热门偏差与图更新滞后。后续系统通常保留低成本协同通道，而不是删除它。

**升级验收**：不仅看相似内容是否符合直觉，还看独有候选、有效消费覆盖、长尾与冷启动，固定总体候选预算。

## 2. R2：特征化双塔 + ANN

`eu=f(user,history,context)`，`ei=g(item,author,content)`，点积或余弦检索；训练可用 sampled softmax、批内对比目标或其他匹配损失。相较矩阵分解，神经塔可以组合属性、内容与上下文，并服务新内容。

**体系变化**：模型训练与近邻索引成为独立但必须一致的产物。距离定义、归一化、负样本分布、内容塔版本和更新频率影响整体效果。双塔限制在于用户内容交互主要通过最终相似度发生，不能廉价地表达精排级复杂交叉。

**列表页重点**：点击召回与消费召回分别评估，避免封面吸引力支配全部候选。**视频流重点**：自动起播不是强正例，用有效观看及其他反馈构造目标。

可执行双塔张量与训练参考 [09](09-retrieval-blueprint.md)。

## 3. R3 的三条并行分支

| 分支 | 机制 | 解决什么 | 主要边界 |
|---|---|---|---|
| 序列/会话 | GRU、Self-Attention、最近行为触发召回 | 当前意图、顺序与兴趣迁移 | 噪声、反馈延迟、长序列计算 |
| 多兴趣 | 路由或多个 query 得到 K 个用户向量，逐兴趣检索 | 单向量压缩损失、兴趣覆盖 | 兴趣塌缩、预算与聚合 |
| 图表征 | 用户-内容/作者/关系图聚合，输出检索向量 | 高阶协同、关系结构 | 图更新、采样偏差与冷启动 |

LightGCN 等是图协同的代表研究方向：图传播突出邻居协同，而不必引入重型内容变换。社交关系图与交互图含义不同；不应仅因存在 GNN 就把所有关系混成同一种边。

MIND/ComiRec 代表多兴趣思路；SASRec 代表自注意力序列思路。它们可以组合，但多兴趣与时序不是同一个问题：多个无序兴趣向量不保证理解“先搜索再消费”的顺序。

**何时采用**：证据显示单向量丢失小众兴趣、会话意图变化或现有共现覆盖不足。先对比更好的简单池化、时间衰减和多通道触发，再判断重模型的增量。

## 4. R3b：内容语义与协同对齐

内容路径从类目/标签，发展到文本编码、图像/视频/音频编码，再到多模态统一空间和教师蒸馏。目标不只是“找意思相似的内容”，还要将语义表征与消费偏好对齐。

可采用内容-协同对比损失、教师向量蒸馏、ID dropout、模态 dropout、分阶段微调。协同教师只在有足够反馈的内容上可靠；新内容不能凭空获得高质量协同标签。

**新内容闭环**：内容编码 → 合适用户小流量探索 → 反馈置信度更新 → 扩大发放 → 索引与召回更新。单独增加一个多模态向量文件不构成冷启动系统。

**未来方向**：更好的语义粒度、时序视频理解、行为与内容共同预训练，以及内容变化和时事漂移下的更新效率。教师体积与离线编码成本也纳入收益。

## 5. R4：从“命中历史正例”到“给后级提供有价值候选”

召回损失常学用户是否与内容交互，精排则优化消费、互动和负反馈；两层存在目标与分布错位。演进包括：

1. 多目标或分通道召回，不把全部价值压成点击；
2. 用精排的任务输出、软排序或候选相对价值蒸馏召回；
3. 动态通道配额，按请求调整兴趣覆盖与探索；
4. 候选来源覆盖和“前级未选择”样本审计，避免自我强化。

更复杂的 late interaction / 多向量内容交互可提高表达能力，但需要相应索引与计算；不能把精排交叉结构直接放进普通 ANN 并假设仍可预计算。

**风险**：教师只见旧候选、蒸馏放大热门偏差、多路分数不可比。先证明同预算下最终有效候选变好，而不是仅教师一致性更高。

## 6. R5：生成式召回与大规模行为序列

### 6.1 从检索向量到生成语义标识

内容编码后用离散量化产生语义码，训练 `P(s1,...,sM | history,context)`，约束解码得到合法候选。TIGER 是这一脉络的代表；本轮没有新增其官方复现核验，技术边界见 [15](15-frontier-portfolio.md)。

价值假设：码前缀可能共享语义，历史与目标的结构可以统一建模。关键难题：码碰撞、新内容及时登记、码本变更、合法内容过滤、beam 开销和热门漂移。

首轮建议作为新召回路，与 ANN 合并；用独有优质候选、最终消费及成本判断，不用 token loss 替代推荐评价。

### 6.2 从小序列编码到可扩展行为模型

HSTU 等研究更适合推荐负载的序列交互和训练/推理协同。它与生成语义 ID 不是同义词：序列模型可以输出向量打分，也可以用于其他任务；“生成式推荐”在不同工作中指代不同范式。

未来应重点探索：多行为序列、长期记忆、当前会话、统一内容语义、多目标适配以及可控计算。是否共享到精排取决于候选交互能力与服务预算。

## 7. 必须同时演进的评估

| 代际变化 | 新增评估维度 |
|---|---|
| CF → 双塔 | 全候选 Recall、ANN 损失、向量空间一致性 |
| 单向量 → 多兴趣/序列 | 低频兴趣、会话迁移、同候选预算、延迟 |
| ID → 多模态 | 按内容时间/曝光量切分、零曝光探索 |
| 匹配 → 蒸馏/多目标 | 教师支持集、最终精排及曝光价值 |
| ANN → 生成式增量 | 解码有效率、候选碰撞、刷新延迟、独有价值 |

不同代际可以长期并存。当前推荐的目标形态是“稳定协同 + 语义/序列/多兴趣 + 受控探索 + 可选生成通道”，而不是单模型全替代。
